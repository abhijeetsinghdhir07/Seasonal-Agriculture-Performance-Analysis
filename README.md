# 🌾 Seasonal Agriculture Performance Analysis

**Overview**
This repository contains the complete data analysis and Jupyter Notebook for the VOIS AICTE Major Project. The primary objective is to investigate how agricultural performance, resource usage, and economic outcomes fluctuate across different seasons (**Kharif, Rabi, and Zaid**).

## 📂 Files Included
* `seasonal_agriculture_performance_dataset.csv`: The raw dataset containing variables like crop type, rainfall, irrigation method, yield, and profit.
* `Seasonal_Agriculture_Analysis.ipynb`: The Jupyter Notebook containing all data cleaning, aggregations, and visualizations.

## 📊 Key Analytical Insights
* **Profitability Fluctuations:** Identified significant variations in average profit across seasons, with Kharif showing the highest returns and Zaid showing average financial losses.
* **Resource Efficiency:** Analyzed the relationship between water usage (`Water_Used_m3`) and actual yield, highlighting the cost burden of water-intensive farming during summer months.
* **Environmental Impact:** Visualized how natural factors like rainfall directly influence crop-specific performance.

## 💻 Technologies Used
* **Python 3**
* **Pandas** (Data manipulation and cleaning)
* **Matplotlib & Seaborn** (Data visualization)
* **Jupyter Notebook** (Development environment)

## 🚀 How to Run
1. Clone this repository to your local machine.
2. Ensure you have Jupyter Notebook and the required Python libraries installed (`pip install pandas matplotlib seaborn`).
3. Open `Seasonal_Agriculture_Analysis.ipynb` and run all cells to view the analysis and charts.
